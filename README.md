# Скрипт настройки безопасности сервера

## Что делает этот скрипт
- Создаем нового пользователя
- Добавление публичного ключа SSH
- Конфигурация SSH
	1. Изменение порта SSH
	2. Запрет авторизации по паролю
	3. Разрешение авторизации по публичному ключу
	4. Ограничение количества попыток входа
	5. Время ожидания перед завершением сессии 30 сек
	6. Установка интервала проверки активности клиента 300 сек
	7. Количество проверок активности перед завершением сессии 2
- Проверка подключения SSH после внесения правок в конфигурацию (не работает, т.к. необходим плный перезапуск сервера командой "reboot")
- Активация Firewall с добавлением порта SSH (по желанию)
- Отключение пингование сервера (по желанию)
- Активация автоматических важных обновлений (по желанию)
- Установка и настройка Fail2ban (по желанию)
- Установка 3X-UI (по желанию)
